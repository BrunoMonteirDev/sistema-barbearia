# Checklist de conformidade

| Item | Situação | Observação |
| --- | --- | --- |
| Template original preservado | Conforme | não foi modificado |
| Mapa do sistema e evidências | Conforme | arquivos criados nesta pasta |
| Texto técnico baseado no código | Em elaboração | artigo Markdown é a fonte editorial |
| Referências verificadas | Parcial | fontes técnicas oficiais verificadas; metodologia pendente |
| Resultados de testes reais | Conforme | registrados em `relatorio-de-testes.md` |
| Figuras atuais sem dados pessoais | Pendente | capturas ainda não produzidas |
| Versão identificada | Pendente | depende dos metadados do autor |
| Versão anônima | Pendente | depende da versão identificada |
| Cobertura mínima de 80% | Não conforme | cliente e servidor abaixo da meta |
| Integração PostgreSQL | Pendente | Docker Desktop indisponível |
| Revisão ortográfica e editorial final | Pendente | executar após texto/figuras no template |
